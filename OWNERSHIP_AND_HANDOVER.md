# Ownership and handover note

This package is intended to let the Hutano.kine owner and their chosen IT/web professional operate the website independently.

## Owner responsibilities

The Hutano.kine owner supplies, pays for and controls:

- the web-hosting account;
- the domain registrar and DNS accounts;
- account recovery and multi-factor authentication;
- final public content, service descriptions and contact details;
- legal notice and privacy information approved for the practice;
- the Doctena account and booking destination;
- ongoing backups, version control, security updates and supplier management.

## Package boundaries

- The package contains only the Hutano.kine static website and handover documentation.
- It contains no marketplace, PocketPals or unrelated project source.
- It contains no patient records, booking records, credentials, API keys, environment files or vendor secrets.
- No SayPeter account, runtime, API or telemetry is required to host or operate this static site.
- No analytics or telemetry is technically necessary. The owner may add privacy-compliant analytics later only after an intentional legal/privacy review.
- Doctena remains the external booking service and is not transferred or embedded as application code.

The source may be placed in a new private repository owned by the practice. No repository was pushed and no new hosting deployment was created as part of this handover preparation.
